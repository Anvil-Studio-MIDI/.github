## What Is Anvil Studio

Anvil Studio is a Windows MIDI sequencer and composition desk. Songwriters and teachers who already sketch at a keyboard use Anvil Studio MIDI sequencer to capture takes, quantize, and arrange tracks. Anvil Studio piano roll is the note grid. Anvil Studio music composition is the habit of building a piece as MIDI. Anvil Studio MIDI project is the file you keep - songs, student etudes, film cues you were hired to sketch.

It will play through a synth you already have (soundfont, hardware, or Windows MIDI). It is not a replacement for a large audio DAW when the job is live vocals and analog outboard, and it is not a typesetting program for a publisher’s engraved edition.

Work on compositions you wrote or were hired to arrange. Keep student files in the class folder you administer. Do not drop a commercial MIDI pack you are not licensed to use into a project you will publish.

## Starting with Anvil Studio

Prerequisites: A PC you administer, a MIDI keyboard or mouse entry, and a piece you have the right to write.

1. **Prepare:** Connect the keyboard you already use, or plan to step-enter the first melody.
2. **Configure:** Create Anvil Studio MIDI project with a tempo and meter for that piece.
3. **Test:** Record a bar into Anvil Studio MIDI sequencer and confirm Anvil Studio piano roll shows those notes.
4. **Refine:** Quantize lightly, add a second track, and set the synth you already run.
5. **Apply:** Arrange Anvil Studio music composition through the form you intended.
6. **Maintain:** Save versions, export SMF if another seat needs it, and keep licensed soundfonts only.
